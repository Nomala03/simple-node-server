Purpose of API Endpoints

    • Organize your server actions
        Different endpoints do different jobs (get, create, update, delete).
      Connect frontend and backend
        Your website or Postman sends a request to your API endpoint and gets data back.
      Control data access
        You can allow only specific types of requests (like allowing only admins to delete).

    • How to Use API Endpoints

    When you write code (for example with Express in Node.js): "app.get('/movies', (req, res) => { res.json([{ id: 1, title: 'Barbie' }, { id: 2, title: 'Spider-Man' }]); });"

    • This creates an endpoint at /movies. It waits for a GET request and sends back a list of movies.
    • When you use Postman or your frontend website:
    • You send a GET request to http://localhost:3000/movies The server responds with the movie list

    • What Kind of Data is Sent to an API?

    Type of Data

    • JSON (JavaScript Object Notation): Most common for APIs (Postman, web apps) Form Data: When submitting HTML forms Multipart Form Data: For file uploads (profile pictures, PDFs) Query Strings: For filters/search via GET requests Raw Text/XML: Rare now; old systems might use XML
